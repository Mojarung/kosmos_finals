# Закупка снимков: запуск и демо

Реализовано 26.09.2026. Экран: **Съёмка → Подобрать снимки**.

## Возможности

- Учебный каталог без сети: зоны объектов, объединённые заказы, широкое покрытие, резервный радар, бесплатная обзорная сцена, непригодные альтернативы. Все цены и сцены предложений явно вымышлены. Исходная модель и объекты остаются из выбранной сцены.
- Поиск реального архива SkyFi по датам и территории сцены: коммерческие/бесплатные/все, первая страница до 50 предложений; неполная выборка обозначена. Сценарий — покупка архива сегодня для ретроспективного разбора.
- Требования к сроку и разрешению, обязательные объекты, исключения предложения/поставщика. Подбор по уникальным объектам без двойного учёта EL.
- Точный поиск по наборам объектов в сохранённом каталоге: максимум охвата EL в бюджете или минимальная цена обязательных требований. При невозможности — явно частичный результат и размер нехватки бюджета, если решение существует.
- Доплата за добавление каждого объекта при сохранении текущего охвата. Сравнение A (пригодные бесплатные данные), B (самый дешёвый пригодный единичный заказ всей сцены), C (корзина). Отдельно сравнение с независимым подбором для тех же охваченных объектов.
- Создание нового контура на обязательные объекты из карточки предложения. Ограничения геометрии проверяются. Изменение контура сбрасывает подтверждение цены и пригодности реального заказа.
- Подсветка выбранных заказов/альтернатив на карте. Расчёт по ТЗ сохраняется отдельно.
- Неизменяемые каталоги и решения в SQLite, история, ZIP: сводка Markdown, полный JSON с происхождением цен, GeoJSON заказов.

## SkyFi

Задать `SKYFI_API_KEY` в окружении backend. Для Docker Compose можно использовать `.env` по образцу `.env.example`: ключ передаётся только серверу. Для локального запуска передать переменную процессу uvicorn. Ключ не хранится в браузере или каталоге.

Используются только `POST /archives` и `POST /order-archive/validate`, по [публичной OpenAPI-схеме](https://app.skyfi.com/platform-api/openapi.json). Вызовов создания заказа нет. Проверка цены может требовать дополнительных прав аккаунта или принятия условий поставщика; ошибки показаны явно.

1. Выбрать SkyFi, период съёмки и найти предложения.
2. В карточке открыть параметры, проверить цену без покупки.
3. Проверить пригодность у объектов по доступным данным и указать основание. Проверка оператором маркируется отдельно; облачность всей сцены автоматически не подтверждает видимость объектов.
4. При необходимости создать отдельный/объединённый контур на обязательные объекты, затем снова проверить цену и пригодность.
5. Подобрать и сохранить корзину. Возвращённая стоимость — оценка поставщика, не оплаченный заказ или гарантия цены.

Авторизованный поиск проверен 26.09.2026: для Nigeria_812045 за сентябрь–октябрь 2018 года предложений нет; за 2025 год получено 50 предложений Sentinel на первой странице. Для одного бесплатного снимка endpoint валидации вернул оценку 0 USD без покупки. Платная котировка пока не проверена. Снимки 2025 года использовались для проверки интеграции и не подтверждают состояние паводка 2018 года. Ключ хранится в локальном .env, исключённом из Git и контекста сборки.

## Устойчивый сценарий показа

1. Нигерия → Съёмка → Подобрать снимки → Учебный каталог → Найти предложения.
2. При бюджете 500 USD и детализации 1 м показать полную корзину. Раскрыть условия оплаты в карточке отдельной зоны.
3. Выбрать обязательный склад, переключить цель на минимальную стоимость обязательного. Показать контур и доплаты у других объектов.
4. Исключить выбранное предложение: появится альтернатива. Вернуть исключённые.
5. Установить бюджет 0: увидеть невыполненные условия и необходимую доплату. Сменить детализацию на 10 м: станет доступен бесплатный учебный вариант.
6. Сохранить и скачать заявку. Изменить условия и открыть сохранённую закупку из истории.

Демонстрационные числа не называть рыночными ценами. Сохранённый каталог SkyFi тоже имеет дату: повторный расчёт корзины не обновляет предложения поставщика. Доставка оценочная. Налоги/сборы отдельно не подтверждены. Охват EL не является предотвращённым ущербом, а покупка не означает, что сомнения устранены.

## Границы версии

Планирование относится ко всей выбранной сцене и фиксированному портфелю, что подписано в интерфейсе. Собственные реестры проектов пока не подставляются в этот подбор. Оптимальность относится к доступному набору кандидатов и сумме зафиксированных цен; скидки между заказами не моделируются. Технический минимум заказа не подменяется минимумом оплаты. UP42, импорт коммерческих предложений, анализ купленных снимков и автоматическая оплата не подключены.

## Проверка разных зон и исправления SkyFi

26.09.2026: GSD SkyFi нормализован из сантиметров в метры с сохранением исходного значения. По умолчанию коммерческий поиск передаёт openData=false; бесплатно и все предложения доступны отдельно. Старые каталоги требуют повторного поиска. Причины непригодности показаны над корзиной; HTTP 429 объясняет ограничение частоты. Дата при переключении территории берётся из новой сцены, без зависимости от скорости загрузки анализа.

Коммерческий поиск за 01.01.2018–21.09.2026: Нигерия — 11 предложений Vantor (0,316–0,586 м); Гана — 15 Vantor (0,343–0,607 м); Меконг — 17 Planet/Vantor (0,327–1,15 м). Один поиск Ганы получил 429, последовательный повтор прошёл. Проверка платной цены для каждой зоны вернула 403: права/условия аккаунта требуют проверки; покупок не было. Это поиск по широкому периоду для проверки коннектора, а не подтверждение паводка 2018 года.

18 сценарных проверок: три зоны × бюджеты 0/100/500 USD × сроки 1/12 ч. Превышений бюджета и повторного учёта объектов нет. При бюджете 500 и 12 ч все 10 объектов охвачены: 308,65 / 308,46 / 304,34 USD соответственно (учебные цены). При сроке 1 ч обязательное условие честно невыполнимо.
