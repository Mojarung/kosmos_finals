# Текущий статус FloodValue

Обновлено **25.09.2026**. Оценка относится к текущему коду FloodValue и к [PDF критериев](source/FloodValue_Критерии_КосмоХакатон.pdf). Это **внутренняя оценка готовности**, а не баллы жюри. Формулировки требований и максимальные баллы определяет PDF; [разбор критериев](07-scoring-checklist.md) помогает найти артефакты.

## Где мы сейчас

- **Работает:** контейнерный Vue/FastAPI сервис с тремя офлайн S1-чипами и поиском Sentinel‑1 RTC для произвольной рамки до 300 км². Сервер на CPU читает VV/VH COG, объединяет соседние кадры одной платформы/орбиты/`datatake`, переводит в dB, запускает пять замороженных U‑Net, кэширует GeoTIFF/слои, отдаёт вероятности, воду, baseline, неопределённость, пиксель, план A/B/C, ZIP и выбор даты. На карте есть схема, спутниковая подложка, прозрачность слоя, радар, локальный вид и глобус. Портфель из 10 точек и V/q вне исходных сцен явно сценарный. Маршрут описан в [README](../README.md).
- **Проверено 25.09:** backend `5 passed`; контейнерные сборки backend/frontend успешны. Чёрный ящик API прошёл путь STAC → VV/VH COG → пять моделей → анализ → пиксель → изменение бюджета/обязательного объекта → 18 файлов ZIP для Нигерии (23.09.2026, 1 кадр, 262144 валидных пикселя, 1,338 км² воды), Нигерии (22.09.2026, 2 соседних кадра, 262144 пикселя, 1,194 км² воды) и Москвы (20.09.2026, 262144 пикселя, 0 км² воды). В браузере рамка 17,39 км² автоматически загрузила снимок 23.09, дала 2,14 км² воды и 3,48 млн ₽ учебного EL; закрепление объекта и бюджет 6500→5000 ₽ изменили C с 3 зон/6116 ₽ на 2 зоны/4177 ₽. На отдельной рамке 11,92 км² один кадр от 22.09 давал 67,3% покрытия, а два кадра того же прохода закрыли её полностью и дали 1,46 км² воды. Дата, число кадров, объекты и оценка обновились в браузере. Пиксель без данных и валидный пиксель проверены. GitVerse не проверялся и не менялся.
- **Ограничение:** мозаика объединяет только кадры одного прохода; пробелы между разными датами не заполняются молча. Если данные частичные, пользователь видит фактическое покрытие и может сменить дату. Есть ограничение 300 км² на один запрос, а качество переноса модели с Sen1Floods11 на RTC в новом регионе пока не проверено ручной разметкой. Спутниковая подложка Esri может иметь другую дату и не участвует в расчёте. Точки объектов, стоимость и срок платной съёмки сценарные; предотвращённый ущерб не измерен.

## Как поддерживать документ

После изменения функциональности, доказательств, ограничений или плана обновлять этот файл **в том же коммите**: дата, проверенный источник, затронутые критерии и следующий шаг. Непроверенное отмечать как предположение; факты о merge, запуске, тестах и сдаче не объединять в одно «готово». Обычные технические коммиты остаются в Git, а этот файл хранит только актуальное состояние и ближайший план.
