## Ближайшие действия для максимума по ТЗ

1. **Доказуемая сдача:** сделать репозиторий/ссылку GitVerse доступными проверяющему, сверить фактический commit с GitHub и весами, автоматически прошить commit в контейнер/ZIP, проверить финальный комплект.
2. **Честные данные:** ввести `as-of` правило для постоянной воды и других вспомогательных источников; если исторического слоя нет, явно пометить ретроспективный разбор и не выдавать его за решение «за 6–12 часов» в 2018 году.
3. **Доказательство качества:** заморозить новое независимое событие до настройки, собрать метки для нескольких живых ROI, проверить перенос, калибровку, неопределённость, швы и сбои.
4. **Решение оператора:** связать импортированные активы с подбором снимков, подтвердить стоимость/пригодность конкретного предложения или оставить цену сценарием; довести новый расчёт прочих затрат и сценарную остаточную неопределённость до экрана и финального ZIP.

Новые тесты, обучение и повторная сборка в ходе этого **аудита** не запускались согласно рабочему ограничению пользователя; выводы о прошлых проверках взяты из сохранённых отчётов.
