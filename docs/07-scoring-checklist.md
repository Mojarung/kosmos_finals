# Критерии оценки и чек-лист

Источник: `FloodValue_Критерии_КосмоХакатон.pdf`. 20 критериев по 0-5 баллов, всего 100.

Жюри проверяет воспроизводимую цепочку: Sentinel-1 → baseline и основной метод → вероятностная карта основного метода → ущерб одного портфеля из 10 объектов → стратегии A/B/C. Оба метода сравниваются на одинаковых независимых валидных пикселях. Экономический контур для baseline не нужен, дополнительные открытые данные разрешены, но не обязательны.

## Где проще всего потерять баллы

- Авторский split без оговорки о пересечении событий (критерий 6). См. [03](03-methods-validation.md#разделение-данных-без-утечки).
- EL обнулен для объектов ниже порога или p взята из маски, а не из вероятностей (13).
- Цены зон сложены из заранее посчитанных одиночных цен без пересчета скидки по корзине (15, 17).
- Ставка 788,64 подписана как тариф, или не сохранено `base_rate_status=scenario` (17, 18).
- Для B и C заявлено снижение неопределенности без новых наблюдений и без статуса `scenario` (16).
- Веса лежат по сторонней ссылке, а не в GitVerse (11).
- В CSV записаны `NaN` или 0 вместо пустого значения (12).
- Маска не совпадает с `p ≥ threshold` из-за постобработки, которая не отражена в метаданных (5, 12).
- Интерфейс при смене бюджета перезапускает inference или меняет порог (19).
