# Путеводитель для жюри: 20 критериев и где их проверить

FloodValue по официальному Sentinel‑1 из Sen1Floods11 строит карту воды двумя методами (порог VH и ансамбль U‑Net с калиброванной вероятностью), считает ожидаемый ущерб `EL = p × V × q` десяти учебных объектов, формирует свои зоны съёмки, оценивает их по формуле ПП РФ № 840 и сравнивает стратегии A/B/C при бюджете. Ниже для каждого критерия: что сделано и где это увидеть. Числа взяты из закоммиченных артефактов; то, что перепроверено повторным запуском 26.09.2026, отмечено отдельно.

Работающий сервис: <http://147.45.153.113>.

## Проверка за 15 минут

```bash
git lfs install --local && git lfs pull                                    # веса S1-ансамбля и next_optical
uv run scripts/fetch_context_weights.py                                    # веса модели с контекстом с Google Drive, sha256 по recipe.json
./scripts/compose.sh up --build                                            # интерфейс http://localhost:18080, API http://localhost:18000/docs
curl -o floodvalue-Nigeria_812045.zip "http://localhost:18080/api/export?scene_id=Nigeria_812045&budget=6500"
uv run --project backend --extra demo python scripts/validate_package.py floodvalue-Nigeria_812045.zip   # "status": "ok"
uv run --project backend python scripts/e2e_official.py http://127.0.0.1:18000 Ghana_1078550          # другой официальный чип
uv run --project backend --extra demo --extra test pytest backend/tests -q                             # тесты бэкенда
cd ml && uv run pytest tests -q                                                                        # 81 тест
```

26.09 эта последовательность пройдена из чистого клона: образ собрался, ZIP из 21 файла прошёл валидатор, в `run_metadata.json` записан ровно собранный commit, чип Ghana_1078550 скачался из официального бакета и посчитался в контейнере на CPU за 34 с (скачивание 2,7 с, модель 24,9 с), 137 тестов бэкенда в том же клоне зелёные. 81 тест ML прогнан в рабочей копии. Позже в сервис вошли next_optical и модель с контекстом: для них нужны полный `git lfs pull` и веса с Google Drive (вторая и третья строки выше), без весов контекста рамка на карте считается S1-ансамблем.
