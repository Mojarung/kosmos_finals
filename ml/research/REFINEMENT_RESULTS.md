# Развитие ансамбля коллеги: сравнение на исходном split

Основная метрика — pooled IoU воды; больше лучше. Оба варианта оценены на одних чипах, одних валидных пикселях и одном устройстве. Ранее опубликованные 0,697 — округлённый результат исходной модели. Ниже её повторный прогон рядом с новым рецептом.

| Часть | Исходный IoU | Новый IoU | Δ IoU | Исходный Brier | Новый Brier |
|---|---:|---:|---:|---:|---:|
| test_core | 0.696958 | 0.704383 | +0.007425 | 0.036010 | 0.035005 |
| test_adjacent | 0.648442 | 0.648484 | +0.000042 | 0.034595 | 0.033638 |
| bolivia | 0.659276 | 0.652735 | -0.006541 | 0.048379 | 0.047881 |

На test_core есть положительный сдвиг, на Bolivia — регрессия. Рецепт остаётся отдельным экспериментальным вариантом; исходный v1 сохранён по умолчанию.

Опубликованные исходные IoU: test_core 0.696559, test_adjacent 0.648114, bolivia 0.655147. Таблица выше использует повторный прогон исходных весов на MPS/FP32; исходная оценка выполнялась на CUDA с AMP. Разницу между опубликованным и повторным результатами не приписываем улучшению модели.

- Коэффициенты: 0.252068, 0.142403, 0.228872, 0.214740, 0.161917.

Проверены обычное продолжение BCE+Dice, переход на BCE+Lovasz, кроп 384, заморозка статистики BatchNorm, TTA и положительные коэффициенты ансамбля. Полный журнал выбора и результаты отдельных обучений сохранены в JSON рядом.

## Ограничения

Парный bootstrap по чипам test_core: 95% интервал Δ IoU [-0.000936, +0.019981]. Это описательная оценка: чипы одного события могут быть зависимы. Малый положительный сдвиг сам по себе не доказывает устойчивый выигрыш на новых событиях.

Validation использовалась адаптивно для нескольких вариантов. Опубликованный исходный test score был заранее известен, но новые test-предсказания получены только после фиксации одного рецепта. Окончательный тест не является CV. Старые event-held-out CV результаты не сравниваются численно с этой таблицей.

cd ml
