# L2A boosting: протокол до эксперимента

Цель — проверить перенос пиксельного бустинга на сервисные Sentinel-2 L2A.
Исходная версия проекта: cae7833. Старые веса и результаты не меняются.

- Только 332 development-чипа из `fresh/folds.json`; пять пространственных фолдов
  без соприкосновения обучающих и внешних чипов. Ни test_core, ни test_adjacent,
  ни Bolivia в загрузку/обучение/выбор не входят.
- S2 L2A из Planetary Computer на допустимую дату S2Hand: от 0 до 2 дней до S1.
  У Ghana/Spain оптики нет. Список STAC items фиксируется до обучения.
  Offset baseline >=04.00 снимается; SCL 0/1/3/8/9/10 недоступны; маска соответствует
  сервисному правилу. Отсутствие данных и ошибка загрузки различаются.
- Признаки: прежние 23 S1 texture, 12 L2A-полос, NDWI/MNDWI/NDVI/AWEI/NDMI,
  средние первых трёх индексов в окнах 3/9, флаг доступной оптики: всего 47.
  При отсутствии оптики её признаки NaN, radar остаётся. Разметка в признаки не входит.
- Три алгоритма: HGB, LightGBM, CatBoost, затем равная смесь. Размеры/параметры
  фиксируются в конфигурации кода. 6000 равномерных пикселей/чип, seed2026.
- Для каждого внешнего фолда следующий `(k+1)%5` служит inner valid; оставшиеся
  три фолда обучают пилот и выбирают число итераций. Затем модель с этим числом
  итераций переобучается на всех четырёх фолдах, не видя внешних меток.
- Основное сравнение с context_model — pooled OOF IoU, порог и Platt по всем OOF,
  как в исходном контекстном протоколе. Это development-результат с подгонкой порога,
  не честная оценка калибровки на новых данных. Отдельно сообщаются IoU при 0,5,
  raw Brier, event IoU и clear/missing-optics срезы.
- Значение context optical OOF 0,760235 — опубликованный ориентир, а не независимо
  воспроизведённый контроль: локально отсутствуют его auxiliary-кэши и OOF logits.
  Новый бустинг пока без DEM/истории/JRC/WorldCover, поэтому это сравнение систем,
  не чистая абляция архитектуры. Смешивание с context до совместимых OOF запрещено.
- Скрининг успешен, если pooled OOF IoU превышает 0,760235. Успех не означает
  автоматического изменения сервиса или опубликованного test-результата.
- Kuro Siwo и TerraMind изучаются отдельно; внешние данные не входят в этот прогон.
