# Продолжение после обновления cae7833

Протокол записан до новых экспериментальных результатов. Рабочие модели не заменяются.

## Быстрый контроль пространственных признаков

Гипотеза: бустингу S1+S2 недостаточно оптических окрестностей 3/9 пикселей;
среднее, стандартное отклонение и локальный контраст NDWI/MNDWI/NDVI в окнах
27 и 81 пиксель могут добавить пространственный контекст без новой нейросети.
Это проверка гипотезы, не заявленный результат из статьи.

- Те же три event-held-out фолда `research/cv_plan.json`; только исходные train+valid.
- Тестовые метки/прогнозы и новые контекстные сети в этот эксперимент не входят.
  Контекстные сети обучены по другим фолдам, поэтому смешивать их прогнозы со старой
  event CV без переобучения нельзя.
- LightGBM с теми же параметрами, seed74 и 10000 пикселей/чип, что прежний `lightgbm`.
  Индексы пикселей воспроизводят `next73:<chip>`; inner valid — 3000 пикселей/чип.
- Исходные 47 признаков плюс 18 пространственных. Метки не участвуют в признаках.
- Сравнения: старый LightGBM против нового при весе оптики 0,75;
  смесь нового с замороженным `boost_learned` с долями нового 0/0,25/0,5/1
  внутри оптической ветки. Параметры прежней смеси берутся отдельно для каждого фолда.
- Калибровка isotonic и порог каждого варианта — только inner valid.
  Внешние события оцениваются на всех прежних валидных S1-пикселях, включая S1 fallback.
- Главная метрика — среднее IoU десяти внешних событий; pooled IoU/Brier и изменения
  по событиям публикуются рядом. Эти результаты — development, не независимый тест.
- Если нет улучшения среднего event IoU относительно `boost_learned`, направление
  не проходит скрининг. Даже положительный результат требует отдельной проверки
  совместимости с L2A и новым пространственным CV перед поставкой в сервис.

## Данные и следующие направления

Открытые каталоги исследуются отдельно. Наличие файла в открытом доступе не означает,
что он независим от наших событий. Перед обучением нужны event/date/footprint-манифест,
исключение совпадающих событий/соседних тайлов и явное приведение классов к «вся вода».
Крупные сторонние наборы и чужие обученные на Sen1Floods11 веса не добавляются
к этому короткому CV-эксперименту.
