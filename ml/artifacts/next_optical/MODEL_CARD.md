# FloodValue: ансамбль бустингов S1+S2

Выбран по среднему IoU на десяти отложенных событиях трёх CV-фолдов.
Параметры зафиксированы до новых test-прогнозов; исходный test уже был известен
по предыдущей серии исследований.

| Метрика | Предыдущий S1+S2 | Этот пакет |
|---|---:|---:|
| Event-CV IoU | 0,774209 | 0,784098 |
| test_core IoU | 0,848688 | 0,849383 |
| test_adjacent IoU | 0,837328 | 0,838132 |
| Bolivia IoU | 0,836838 | 0,837351 |

Прирост на test небольшой. 95% описательный парный bootstrap разности
test_core IoU: [-0,001081; +0,002369]; чипы одного события могут коррелировать.

Состав: 25% прежнего S1-ансамбля из пяти U-Net/ResNet34 с rot4 и 75% оптической
смеси. Внутри оптической смеси: прежний HGB 0,040076; увеличенный HGB 0,374250;
LightGBM 0,103298; CatBoost 0,482376. Точные значения и isotonic-калибровка
сохранены в `recipe.json`; порог **0,46**. Новые нейросети не включены:
они не превзошли выбранную смесь на event CV.

Входы: две полосы S1 в dB и, при наличии, 13 полос S2Hand reflectance×10000
на той же сетке. S2 допускается в дату S1 или на 1–2 дня раньше; иначе
используется S1 fallback. Облачные и отсутствующие S2-пиксели не исключаются
из оценки S1. Полноценной QA-маски облаков у этого набора нет.

Ручные метки Sen1Floods11 получены исправлением классификаций S2. Это
преимущество источника входных данных учитывается при сравнении с S1-only;
приведённый результат нельзя выдавать за результат модели только по S1.

Запуск из `ml/`:

```bash
uv sync --group research
# На Mac, если LightGBM не находит OpenMP:
export DYLD_LIBRARY_PATH="$PWD/.venv/lib/python3.13/site-packages/torch/lib${DYLD_LIBRARY_PATH:+:$DYLD_LIBRARY_PATH}"
uv run floodvalue infer --chip Bolivia_103757 --recipe artifacts/next_optical/recipe.json --out outputs/next_Bolivia_103757
```

GPU не требуется. Для своего GeoTIFF используются `--s1`, `--s2`,
`--s1-date`, `--s2-date`; `--no-optical` принудительно включает fallback.
Выходы: `flood_probability.tif`, `flood_mask.tif`, `flood_uncertainty.tif`.
Последний файл измеряет расхождение моделей, а не доверительный интервал.
На пикселях с оптикой: sqrt(0,25×(p_opt−p_s1)² + 0,5×Var_opt);
на остальных — стандартное отклонение радарного ансамбля.

Все веса внутри этого каталога; обучение и `runs/` для инференса не нужны.
SHA256 проверяются при загрузке. `source_recipe.json` и `selection_audit.json`
сохраняют происхождение выбора. Исходный пакет `artifacts/goal072_optical`
не перезаписан. Результаты и ограничения: [полный отчёт](../../research/NEXT_RESULTS.md).
