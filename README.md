# FloodValue — оперативный атлас паводка

Прототип для **инфраструктурного оператора**. На 3D Земле оператор выбирает участок, видит доступное наблюдение и учебный портфель объектов, сравнивает открытые данные (A), широкую съёмку (B) и план под бюджет (C). Срок, приоритет и обязательный объект меняют корзину без повторного анализа снимка.

> Сейчас готовы продуктовый интерфейс и расчётный бэкенд. **ML ещё не подключён.** Водный слой — ручная эталонная метка Sen1Floods11, вероятности объектов — независимые сценарные значения. Ожидаемый ущерб и эффект планирования в интерфейсе имеют статус сценария. Экспорт не является итоговым комплектом ML-артефактов кейса.

## Запуск

Нужен Podman с Compose или Docker Compose. Компактные демо-артефакты уже лежат в `data/demo`.

```bash
podman compose up --build
# либо: docker compose up --build
```

Интерфейс: `http://localhost:18080`. API и схема: `http://localhost:18000/docs`. Порты можно изменить через `WEB_PORT` и `API_PORT`.

На текущей macOS-машине Podman запустил контейнеры, но штатный проброс из VM не открыл порты на хосте. В отдельном терминале работает локальный туннель без изменения конфигурации VM:

```bash
python3 scripts/podman_tunnel.py
```

Он использует SSH-настройки `podman machine inspect` и публикует только два порта FloodValue на `127.0.0.1`; `Ctrl-C` закрывает туннель. На Docker и исправно работающем Podman туннель не нужен.

Локальная разработка:

```bash
uv sync --project backend --extra demo --extra test
backend/.venv/bin/uvicorn app.main:app --app-dir backend --reload
cd frontend && npm ci && npm run dev
```

## Данные демо

Источник: [официальный Sen1Floods11](https://github.com/cloudtostreet/Sen1Floods11), бакет `sen1floods11/v1.1`, чип `Ghana_313799`, снимок S1 и `LabelHand`. Ручная метка различает воду, сушу и невалидные пиксели; она не отделяет постоянную воду от паводковой. В репозитории лежат только полученные из чипа компактные артефакты и манифест с SHA-256 исходников. Для повторной подготовки скачайте файлы в `data/source`:

```bash
mkdir -p data/source
curl -fL -o data/source/Ghana_313799_S1Hand.tif \
  https://storage.googleapis.com/sen1floods11/v1.1/data/flood_events/HandLabeled/S1Hand/Ghana_313799_S1Hand.tif
curl -fL -o data/source/Ghana_313799_LabelHand.tif \
  https://storage.googleapis.com/sen1floods11/v1.1/data/flood_events/HandLabeled/LabelHand/Ghana_313799_LabelHand.tif
uv sync --project backend --extra demo
backend/.venv/bin/python scripts/prepare_demo.py
```

Скрипт проверяет размеры, CRS и совмещение сеток, создаёт визуальные слои, пиксельную маску и 10 точек портфеля с seed `2026`. Координаты точек выбираются только по валидности S1. Значения `p` генерируются отдельно и не берутся из метки или снимка. Демо покрывает **один** чип. Выделить можно любой регион; вне чипа приложение показывает отсутствие наблюдений.

## Что проверить

1. Нажмите «К чипу ↗», включите радар и водный слой. Переключитесь на «Планета», затем выделите двумя кликами произвольный регион.
2. Измените бюджет, срок или приоритет. План C и метрики пересчитаются по тем же объектам; для каждой корзины объёмная скидка считается заново.
3. Выберите объект в списке или на карте, закрепите его в плане. Если срока или бюджета не хватает, появится причина.
4. Переключите A/B/C и экспортируйте сценарный ZIP с анализом, каталогом зон и манифестом источника.

## Метрики и границы

| Число на экране | Значение | Статус |
|---|---|---|
| Площадь воды | Ручные пиксели `LabelHand = 1` в выбранной области; площадь по равновеликой EPSG:6933 | наблюдение в датасете, не вывод ML |
| Экспозиция объектов | `Σ p × V × q`, где p — сценарий, V и q — учебная таблица кейса | сценарий |
| Охват плана | EL уникальных объектов внутри своевременных зон / EL портфеля | сценарий; **не предотвращённый ущерб** |
| Экономия к B | Стоимость широкой корзины B минус стоимость C | сценарная стоимость данных, не общий экономический эффект |
| Стоимость данных | `Б × К × О × П × Т × Р`; Б = 788,64 ₽/км², L2, internal, новая съёмка, скидка по всей корзине | ставка сценарная, не котировка |

Цена реализована по [разбору кейса](docs/05-procurement-pricing.md); контрольный пример 1 км² = 1 703,46 ₽ проверяется unit-тестом. Зоны — квадраты от 1 км² вокруг объектов и весь чип. Доступность новой съёмки через 6 часов — сценарное условие.

```bash
backend/.venv/bin/pytest backend/tests -q
cd frontend && npm run build
```

## Структура

- `backend/app` — FastAPI, региональные метрики и точный перебор корзин.
- `frontend/src` — Vue, 3D Globe на MapLibre, панели оператора.
- `data/demo` — сгенерированные из официального чипа лёгкие данные.
- `scripts/prepare_demo.py` — воспроизводимая подготовка чипа.
- `docs/source` — исходные PDF и ссылка организатора; `docs/*.md` — подробный разбор кейса.
- [Продуктовые решения и следующая ML-интеграция](docs/product.md).

API не требует Kafka, Redis или внешней LLM: каталог мал, а пересчёт выполняется в одном запросе. Ключ, присланный для возможного LLM, не используется и не хранится в проекте.
